\chapter{Contribuciones Originales Esperadas}
Las principales contribuciones de este trabajo pueden resumirse en:

\begin{itemize}
    \item \textbf{Modelo de Clasificación Adaptativa para Componentes Ionic (Nivel Teórico)}:
    \begin{itemize}
        \item Algoritmo \texttt{CLUSTest-Ionic} que combina métricas estáticas (complejidad ciclomática) con dinámicas (historial Git) para priorizar componentes críticos
        \item Aporte al área de \textit{Software Metrics} con una nueva métrica compuesta específica para aplicaciones híbridas
    \end{itemize}
    
    \item \textbf{Patrón "Test-As-Code" para Gestión de Pruebas (Nivel Metodológico)}:
    \begin{itemize}
        \item Framework que trata las pruebas como artefactos versionables y generables mediante CI/CD
        \item Contribución a \textit{DevOps for Mobile} con flujos estándar para Ionic
        \item Plantillas abiertas para GitHub Actions/GitLab CI
    \end{itemize}
    
    \item \textbf{Modelo de IA Especializado en Testing para Ionic (Nivel Práctico)}:
    \begin{itemize}
        \textit{DeepSeek-IonicTest}: Primer modelo fine-tuned para generación de pruebas en Angular/Ionic
        \item Dataset público de 1,200+ componentes etiquetados
        \item Aporte al \textit{AI for Software Engineering} en dominio móvil híbrido
    \end{itemize}
    
    \item \textbf{Benchmark para Testing en Aplicaciones Híbridas (Nivel Evaluativo)}:
    \begin{itemize}
        \item Métricas estandarizadas para comparar herramientas de testing en Ionic
        \item Contribución a \textit{Software Quality} con casos de prueba de referencia
    \end{itemize}
\end{itemize}

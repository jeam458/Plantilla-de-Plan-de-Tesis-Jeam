\section{Objetivos de la Investigación}
\label{chap:objetivos}

\subsection{Objetivo General}
\label{sec:objetivo_general}
Desarrollo y evaluación de un módulo de simulación de APIs nativas de Capacitor para mejorar pruebas unitarias y cobertura de código, con orquestación auxiliar mediante MCP, en entornos basados en Node.js para aplicaciones Ionic.

\subsection{Objetivos Específicos}
\label{sec:objetivos_especificos}

\begin{enumerate}[label=\arabic*., leftmargin=*]
    \item \label{obj:simulador}
    Diseñar y programar un \textbf{bridge universal extensible} de simulación con perfiles de éxito, error, permisos y datos límite alineados al contrato de las APIs nativas de geolocalización, cámara y preferencias.

    \item \label{obj:integracion}
    Integrar el módulo en \textbf{al menos un proyecto Ionic de referencia} con pasos reproducibles en el ciclo de pruebas unitarias en Node.js.

    \item \label{obj:cobertura}
    Implementar un \textbf{procedimiento de cobertura en Node.js} (Jest y/o Jasmine) que eleve líneas y ramas del código expuesto a APIs nativas mediante escenarios sistemáticos.

    \item \label{obj:mcp}
    Desarrollar una \textbf{capa auxiliar de orquestación basada en MCP} para conmutar perfiles de hardware de forma dinámica desde agentes o scripts de prueba.

    \item \label{obj:mcp_valor}
    Evaluar la viabilidad de ejecutar el módulo de simulación y la capa MCP en flujos de \textbf{integración continua}, eliminando dependencias no deterministas.

    \item \label{obj:metricas}
    Establecer y documentar una \textbf{línea base experimental} en el proyecto de referencia para contrastar cobertura ($\Delta C$) y tiempo de diagnóstico ($T_{diag}$) antes y después de la intervención.

    \item \label{obj:transferencia}
    Validar la \textbf{extensibilidad} del módulo mediante la incorporación de nuevos contratos de APIs nativas sin modificar el núcleo del bridge universal.
\end{enumerate}

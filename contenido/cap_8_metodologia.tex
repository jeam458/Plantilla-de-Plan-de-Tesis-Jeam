\chapter{Metodología de Investigación}
\label{chap:metodologia}

\section{Diseño General de la Investigación}
\label{sec:diseno_investigacion}
Esta investigación empleará un diseño experimental con enfoque mixto (cuantitativo-cualitativo) para validar el sistema propuesto. Siguiendo el modelo DSR (Design Science Research), constará de tres ciclos iterativos:

\begin{enumerate}
\item \textbf{Prototipado}: Desarrollo incremental del sistema
\item \textbf{Validación Técnica}: Métricas de rendimiento
\item \textbf{Validación en Contexto}: Aplicación en proyectos reales
\end{enumerate}

\section{Población y Muestra}
\label{sec:poblacion_muestra}

\subsection{Proyectos de Estudio}
\begin{itemize}
\item \textbf{Criterios de selección}:
\begin{itemize}
\item Aplicaciones Ionic 6+ con Angular
\item 50+ componentes declarados
\item Historial Git \geq 6 meses
\end{itemize}
\item \textbf{Muestra}: 3 proyectos open-source (health, e-commerce, education) + 2 proyectos empresariales colaboradores
\end{itemize}

\subsection{Participantes}
\begin{itemize}
\item 10 desarrolladores Ionic (5 seniors, 3 mid-level, 2 juniors)
\item 2 QA engineers especializados en testing automatizado
\end{itemize}

\section{Variables de Estudio}
\label{sec:variables_estudio}

\subsection{Variables Independientes}
\begin{itemize}
\item Método de generación (manual/automático)
\item Nivel de complejidad del componente (1-3)
\item Tipo de componente (visual/servicio/pipe)
\end{itemize}

\subsection{Variables Dependientes}
\begin{itemize}
\item \textbf{Eficiencia}:
\begin{itemize}
\item Tiempo generación pruebas (min/componente)
\item Tiempo mantenimiento (horas/semana)
\end{itemize}
\item \textbf{Calidad}:
\begin{itemize}
\item Cobertura (línea, función, rama)
\item Bugs detectados pre-producción
\item Puntuación CodeClimate
\end{itemize}
\item \textbf{Usabilidad}:
\begin{itemize}
\item SUS Score (System Usability Scale)
\item Percepción de utilidad (entrevistas)
\end{itemize}
\end{itemize}

\section{Desarrollo del Sistema}
\label{sec:desarrollo_sistema}

\subsection{Arquitectura del Sistema}
\begin{itemize}
\item \textbf{Backend}: Python 3.10 (FastAPI, LibCST)
\item \textbf{IA}: DeepSeek-V2 fine-tuned con 1500 ejemplos Ionic
\item \textbf{Frontend}: Plugin VSCode para interacción
\end{itemize}

\subsection{Flujo de Implementación}
\begin{enumerate}
\item \textbf{Análisis de Repositorio}:
\begin{itemize}
\item Scan inicial con SonarQube
\item Clustering de componentes
\end{itemize}
\item \textbf{Generación Adaptativa}:
\begin{itemize}
\item Templates por nivel de complejidad
\item Context injection desde código fuente
\end{itemize}
\item \textbf{Integración CI/CD}:
\begin{itemize}
\item GitHub Actions para ejecución
\item Reportes dinámicos en Pull Requests
\end{itemize}
\end{enumerate}

\section{Procedimiento Experimental}
\label{sec:procedimiento_experimental}

\subsection{Fase 1: Línea Base}
\begin{itemize}
\item Desarrollo manual de pruebas para 20 componentes muestra
\item Medición de tiempo y cobertura inicial
\item Identificación de pain points mediante entrevistas
\end{itemize}

\subsection{Fase 2: Validación Técnica}
\begin{itemize}
\item Pruebas A/B para mismos componentes
\item Métricas comparativas:
\begin{itemize}
\item Precisión generación (F1-score)
\item Reducción falsos positivos
\end{itemize}
\end{itemize}

\subsection{Fase 3: Validación en Contexto}
\begin{itemize}
\item Despliegue en 1 proyecto real por 8 semanas
\item Monitoreo continuo mediante:
\begin{itemize}
\item SonarQube para calidad
\item Jira para tracking de bugs
\end{itemize}
\end{itemize}

\section{Análisis de Datos}
\label{sec:analisis_datos}

\subsection{Cuantitativo}
\begin{itemize}
\item ANOVA para comparación de medias
\item Correlación de Pearson (complejidad vs tiempo)
\item Regresión lineal para predicción de cobertura
\end{itemize}

\subsection{Cualitativo}
\begin{itemize}
\item Análisis temático de entrevistas
\item Affinity diagram para pain points
\end{itemize}

\section{Consideraciones Éticas}
\label{sec:consideraciones_eticas}
\begin{itemize}
\item Anonimización de datos empresariales
\item Consentimiento informado para desarrolladores
\item Opción de opt-out en cualquier fase
\end{itemize}

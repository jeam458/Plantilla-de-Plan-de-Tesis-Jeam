{\bf RESUMEN}

\vspace{1cm}

La calidad del software es uno de los temas que más investiga la comunidad informática, ya que el fin último es poder ofrecer un producto de calidad a los clientes, ya sean personas individuales o empresas. Se entiende por calidad al cumplimiento de las expectativas y requerimientos establecidos por los usuarios, así como de normativas o estándares. La calidad de un software puede medirse desde diferentes perspectivas, siempre en relación a mitigar el riesgo y las fallas mediante métodos de testing y verificación del software en fase de análisis, desarrollo y pruebas. En base a este concepto nace una de las técnicas de aseguramiento de calidad llamadas Pruebas Unitarias.

Las pruebas unitarias son una estrategia ampliamente utilizada y reconocida en la gestión de invenciones a los errores en las aplicaciones móviles, las cuales es la temática sobre la que versa este trabajo. Durante el desarrollo de este trabajo se implementará automáticamente pruebas unitarias aplicables a una aplicación móvil creada en IONIC, mediante un sistema de testing automatizado. Con ello se introduce la investigación sobre el funcionamiento de dicha herramienta de automatización y las prácticas más indicadas para el desarrollo de pruebas unitarias guiadas por el estudio de verbosidad en lenguajes generales de test, haciendo mención a errores más frecuentes a la hora de realizar las pruebas automatizadas mediante la discusión con el equipo de testing responsable de tal aplicación en el taller adaptado para tal fin.
